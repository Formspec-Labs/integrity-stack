# `@formspec-org/integrity-signature-adapter-webcrypto`

The WebCrypto signature adapter. The [`@formspec-org/integrity-signature-port`](../integrity-signature-port) `Verifier` implemented on WebCrypto — browsers and Node alike — over [`@formspec-org/integrity-cose`](../integrity-cose) envelopes.

```sh
npm install @formspec-org/integrity-signature-adapter-webcrypto
```

Part of [integrity-stack](https://github.com/Formspec-Labs/integrity-stack) — shared integrity primitives for the Formspec stack. Apache-2.0.
