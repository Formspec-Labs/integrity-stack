# `@formspec-org/integrity-cose`

COSE_Sign1 byte helpers. Decode and inspect `COSE_Sign1` envelopes and enforce method dispatch on the protected header, so a verifier only ever runs the algorithm the envelope declares.

```sh
npm install @formspec-org/integrity-cose
```

Part of [integrity-stack](https://github.com/Formspec-Labs/integrity-stack) — shared integrity primitives for the Formspec stack. Apache-2.0.
