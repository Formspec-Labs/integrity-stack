# `@formspec-org/integrity-signature-port`

The signature verifier port. The `Verifier` port every signature adapter implements, and the `VerificationReceipt` shape it returns — no cryptography here, only the contract. Adapters: [`@formspec-org/integrity-signature-adapter-webcrypto`](../integrity-signature-adapter-webcrypto).

```sh
npm install @formspec-org/integrity-signature-port
```

Part of [integrity-stack](https://github.com/Formspec-Labs/integrity-stack) — shared integrity primitives for the Formspec stack. Apache-2.0.
